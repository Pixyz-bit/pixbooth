# PhotoPix

Browser photo booth built with React JS. Choose one of seven single/strip/grid templates, enable the webcam, preview, count down, and capture one photo per click. The default is the four-photo classic strip. Templates lock after the first capture; start a new session to change layout. Optional face stickers are None, Dog, Hat, and Glasses; the selected overlay tracks the face and is baked into each captured photo.

After the layout is complete, Start over discards the session and Submit opens a separate editor at `#/edit`. Choose from six background designs and six photo filters, preview the finished layout, and download its JPG. Export dimensions are fixed per template, independent of camera resolution: 900 × 675px photo cells, 36px outer padding, 23px gaps, and a 126px branding footer. Preserve the full source frame with letterboxing; background and filter choices in the download match the editor preview.

Photos stay in browser memory and disappear on reload; opening `#/edit` without a completed session returns to the booth. There are no uploads, accounts, backend, or persistence. Camera access is explicit. Stop tracks after layout completion, cancellation, and unmount. Face detection runs on the CPU in a browser worker using locally served, pinned MediaPipe 0.10.32 assets; photo pixels and landmarks are never uploaded. Camera permissions and real-device compatibility require verification.
