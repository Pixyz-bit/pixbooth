# PhotoPix

Browser photo booth built with React JS. Choose one of seven single/strip/grid templates, enable the webcam, preview, count down, and capture one photo per click. The default is the four-photo classic strip. The capture template locks after the first photo; start a new session to change the required photo count. The camera fills the flexible center column and contains the full source frame. Captured photos appear individually in the right-hand gallery; the composed layout is rendered after Submit. The PhotoPix logo sits inside the camera panel above Camera preview, with no global header.

Choose None or one of 36 face-tracked effects from a searchable collection: Animals (8), Eyewear (7), Headwear (10), and Fun (11). Thumbnail, live preview, and captured photo use the same canvas artwork renderer. Effects are baked into each photo, and switching between active effects retains the face-tracking worker.

After the capture session is complete, Start over discards it and Submit opens a separate editor at `#/edit`. Select a compatible layout with the same photo count, choose from six background designs and six photo filters, preview the finished layout, and download its JPG. Four-photo and six-photo sessions can switch between strip and grid formats without recapturing. Export dimensions are fixed per template, independent of camera resolution: 900 × 675px photo cells, 36px outer padding, 23px gaps, and a 126px branding footer. Preserve the full source frame with letterboxing; background and filter choices in the download match the editor preview.

Photos stay in browser memory and disappear on reload; opening `#/edit` without a completed session returns to the booth. There are no uploads, accounts, backend, or persistence. Camera access is explicit. Stop tracks after layout completion, cancellation, and unmount. Face detection runs on the CPU in a browser worker using locally served, pinned MediaPipe 0.10.32 assets; photo pixels and landmarks are never uploaded. Camera permissions and real-device compatibility require verification.
